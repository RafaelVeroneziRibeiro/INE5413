# INE5413 - Graphs (Grafos) 

[![Language](https://img.shields.io/badge/Language-C++-blue.svg)](#)
[![Status](https://img.shields.io/badge/Status-Work%20in%20Progress-yellow)](#)

This repository contains the practical activities developed for the **INE5413 - Grafos** course at the Federal University of Santa Catarina (UFSC). 

The main objective of this repository is to provide efficient computational representations of graphs and implement classic algorithms to solve modeling problems.

The practical evaluation of the course is divided into three main activities (A1, A2, and A3). 


##  How to Compile
Each activity folder contains its own source code and a specific `README.md` with instructions on how to compile and run the programs via the terminal.
